# Security Policy

This repository is Quad4's fork of [Verdaccio](https://verdaccio.org).

## Supported versions

This fork tracks the upstream `9.x` experimental line on `master`. Only the
latest commit on `master` and the latest tagged release are supported.

## Reporting a security issue

Please *DO NOT* file a public issue. Instead, file a
[private security advisory](https://github.com/Quad4-Software/verdaccio/security/advisories)
against this repository.

If the vulnerability is in unmodified upstream code, consider reporting it to
the upstream project instead. Their disclosure policy, PGP key, and contact
details are in the upstream
[SECURITY.md](https://github.com/verdaccio/verdaccio/blob/master/SECURITY.md).
